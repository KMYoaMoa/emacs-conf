** Emacs Basics

*** Files and Buffers

You are not editting files with Emacs.

Emacs copies the contents of the file to a temporary buffer, and you are editting the buffer.

The file doesn't change until you save the buffer. 

*** File Operations

A temporary buffer under the modeline is called the /minibuffer/.

You already know that you can open a file with ~C-x C-f~, but you may not know that you can also do this with ~C-x C-v~. This will put the current file name in the minibuffer when you are searching for file. 

When you are searching for a file, the "current directory" comes from the current buffer.

To Save a file, you can use ~C-x C-w~, representing ~write-file~. This means "Save as" and will let you to specify a file name. If you just press Enter, then it is the same as ~C-x C-s~.

*** Modes

The behavior in different modes are different. It makes Emacs senstitive to what you are doing.

Major Mode and Minor Mode:

A buffer can be in only one major mode at a time. Here are some common modes:

| Mode          | Function                |
| Fundamental   | Default                 |
| Text          | Writing                 |
| View          | Read Only               |
| Shell         | Running a Shell         |
| Outline       | Writing Outlines        |
| Indented Text | Automatically Indenting |
| Picture       | Creating ASCII Drawings |
| LaTeX         | Formatting Tex Files    |
| Compilation   | Compiling Programs      |

Emacs will detect the extension of the file to put you into the correct major mode.

There are also minor modes: defining a particular aspect of Emacs's behavior and can be turn on and off.

| Mode      | Function               |
| Auto-fill | Enables Word Wrap      |
| Overwrite | Replacing Characters   |
| Auto-save | rt                     |
| Isearch   | Searching              |
| Flyspell  | spell checker          |
| Abbrev    | Use word abbreviations |
| Refill    | fill paragraphs        |
| Artist    | Create ASCII Drawings  |
| Outline   | ...                    |

Some modes are both major modes and monor modes. This allow these mode to be used alone as major mode or to be used with other major modes as minor mode.

** Command Execution
	
To run a command without opening a terminal, you can use:

~M-!~ (Meta+Shift+1) for ~shell-command~

~M-|~ (Meta+Shift+\) for ~shell-command-on-region~, which pipes the selected region to stdin.

By adding ~C-u~ before them, we can directly put the output into buffer

** Key Mapping

*** Concepts

A Keymap is a collection of key bindings.

The basic default key bindings in emacs are kept in ~global-map~.

Another concept is /local keymap/, used to implement commands in modes. Different modes has its own keymap, installs as the local map when invoked.

There are some reserved keymaps.

ctl-x-map for ~C-x ...~
esc-map for ~ESC ...~

*** How to set keys

#+begin_src emacs-lisp
;; General
(define-key keymap "keystroke" 'command-name)

;; set to global map only
(global-set-key "keystroke" 'command-name)
;; eq to
(define-key global-map "keystroke" 'command-name)

;; binds to the local map of current buffer
;; used for temporary key bindings
(local-set-key "keystroke" 'command-name)
#+end_src

Examples

#+begin_src emacs-lisp

;; All these 3 are equivalant
(global-set-key "C-x l" 'goto-line)
(define-key global-map "C-x l" 'goto-line)
(define-key ctl-x-map "l" 'goto-line)

#+end_src

*** How to unset keys

#+begin_src emacs-lisp

(define-key some-map "some key" nil)
